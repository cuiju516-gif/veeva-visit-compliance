## 一处说明

第 ③④ 条是纯函数的边界值，用 HTTP 请求"证明"它们是自欺欺人——同一条规则在 299 秒和 300 秒上的差别，
只有在把输入掐到那一秒时才有意义。所以脚本对这两条只打印对应单测的名字，不伪造一个"通过"。

第 ⑨ 步是目前唯一需要直接写库的地方：管理员的主数据 CRUD 不在本期范围（`实现范围与改造清单.md` §1），
所以软删是拿 psql 做的。缺 `psql` 时脚本会直接退出并说明原因，而不是把"没执行"记成"通过"。
